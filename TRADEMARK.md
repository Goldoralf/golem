# Trademark Policy (golem & golem.fm)

> The French text below is the lawyer's original (2026-10-20) and prevails; the English text is its translation.

The source code of **golem** is available under the GNU GPL v3 free software licence (and MIT for some
components). However, in accordance with **Section 7(e) of the GNU General Public License v3**, the software
licence **grants no right to use the trademarks, product names, domain names or logos** belonging to the
project's publisher ("golem", "Golem ONE", "golem.fm" and the associated logos).

This policy lets the community modify and redistribute the code freely while avoiding any confusion for
musicians about the official origin of the software or of the hardware.

## 1. What is allowed without prior agreement

- **Building without modification:** building and installing the official, unmodified code on your own computer
  or box, for your personal use or with your band.
- **Descriptive reference:** stating truthfully and factually that a project, a plugin or a fork is "compatible
  with golem" or "based on the source code of the golem project", without suggesting any official affiliation or
  endorsement.

## 2. What is forbidden without written agreement (forks must rebrand)

- **Distributing modified versions (forks):** if you publicly distribute a modified version of the software (as
  modified source code, an installer, an ISO disk image or pre-installed hardware), **you must remove every
  mention of the name "golem" and the associated logos** from the user interface, the start screen, the
  executable's name and your communication material. You must choose a distinct name.
- **Selling hardware:** selling or renting a computer box or audio rack under the name "golem" or "Golem Rack"
  is strictly forbidden, even if it runs the official, unmodified software.

# Politique de Marque (golem & golem.fm)

Le code source de **golem** est disponible sous licence libre GNU GPL v3 (et MIT pour certains composants).
Cependant, conformément à la **Section 7(e) de la GNU General Public License v3**, la licence du logiciel
**n'accorde aucun droit d'utilisation sur les marques commerciales, noms de produits, noms de domaine ou logos**
appartenant à l'éditeur du projet (« golem », « Golem ONE », « golem.fm » et les logos associés).

Cette politique vise à permettre à la communauté de modifier et redistribuer librement le code tout en évitant
toute confusion pour les musiciens quant à l'origine officielle du logiciel ou du matériel.

## 1. Ce qui est autorisé sans accord préalable

- **Compilation sans modification :** Compiler et installer le code officiel non modifié sur votre propre machine
  ou boîtier pour votre usage personnel ou avec votre groupe.
- **Référence descriptive :** Indiquer de manière véridique et factuelle qu'un projet, un plugin ou un fork est
  « compatible avec golem » ou « basé sur le code source du projet golem », sans suggérer d'affiliation ou
  d'approbation officielle.

## 2. Ce qui est interdit sans accord écrit (Obligation de Rebranding pour les forks)

- **Distribution de versions modifiées (Forks) :** Si vous distribuez publiquement (sous forme de code source
  modifié, d'installateur, d'image disque ISO ou de matériel pré-installé) une version modifiée du logiciel,
  **vous devez retirer toute mention du nom « golem » et les logos associés** de l'interface utilisateur, de
  l'écran de démarrage, du nom de l'exécutable et de vos supports de communication. Vous devez choisir un nom
  distinct.
- **Vente de matériel :** Il est strictement interdit de vendre ou de louer un boîtier informatique ou rack audio
  sous le nom « golem » ou « Golem Rack », même s'il exécute le logiciel officiel non modifié.
