# Audit 2026-10-15 — pre-publication audit (v2.8.0)

> **Status: CODED** — incident report. Four read-only audits before publishing the repository (security,
> REAPER side, technical debt, platform status), then five fix batches applied the same day; remaining items are
> listed at the end of each section.

Findings came from reading the code unless marked "verified". REAPER-side findings were confirmed partly in REAPER
(§2).

## 1. Security

### Critical findings (fixed)

| # | Finding | Scenario | Fix |
|---|---|---|---|
| S1 | **Code execution by a paired device** (verified). `POST /api/integrations` was not admin-only; `tools/t3k.py` wrote the raw value into `.env`; `bridge/config.py` reloaded every key; `provision/serve-rig.sh` sourced `.env` | a value like `x\nLD_PRELOAD=<uploaded .so>` then `/api/system/bridge-restart` runs code in every ffmpeg/curl | `tools/t3k.py` `env_set` refuses keys/values outside `[A-Za-z0-9_.:/+=-]`; `_load_dotenv` loads only `GOLEM_*`, `T3K_*`, `GOLEMFM_*` and `GOOGLE_API_KEY` (`_DOTENV_PREFIXES`); `/api/integrations` and `/api/system/bridge-restart` are admin-only |
| S2 | **A non-admin phone could redirect the golem.fm link** (`base_url`/`token` writable) — `routes_content.py`, `connect.py`, `auth.py` | point the rack at a fake server that approves its own pairing ticket, get an admin device, then drive the whole job queue (presets, modes, takes, diagnostics, backups) | `base_url` admin-only; `routes_content.server_url_ok`: `https://` required except for this machine, a private IP or a `.local` name |
| S3 | **SSRF via kit import, result readable without a token** — `kit_import.py` fetched any http(s) URL with no size cap; `app.py` served `/library/.import/…` | the bridge fetches itself on `127.0.0.1` (auto-admin): Wi-Fi key QR, backups, diagnostics; anyone on the LAN reads the result | every resolved address must be public, re-checked on each redirect, 4 GB cap; `/library/.<hidden>` answers 404 |
| S4 | **DNS rebinding**: a website open on the rack's machine becomes admin (Origin compared with the client's `Host`, localhost auto-authenticated, no host allowlist) | critical on a desktop install where someone browses | `auth.host_ok`: `Host` must be an IP, `localhost`, the machine name or a `.local` name (`GOLEM_ALLOWED_HOSTS` adds names); HTTP and WebSocket |

### Other findings

- **Tiers too broad** — any paired device, even a 24 h guest, could delete presets, patches, takes, kits… and edit
  modes, input map, devices, recorder, start jobs. **Fixed**: writing a mode, the recorder, the input map, devices,
  or starting the job queue is admin-only (reading stays allowed); a guest device can no longer DELETE anything.
- **Public reads without a token** (`/api/peaks?file=recordings/…`, `/api/sample`, `/api/kits/import/job/*`).
  **Fixed**: they require a token.
- **Path checks on Windows** (`/api/loop` accepted `C:x`, `/api/sample` a sibling folder). **Fixed**: `_within`
  (realpath).
- **Animation packs** CSS filter bypassable (escaped `url(`, `image-set()`, sibling combinators). **Fixed**: CSS
  escapes decoded before checking; `image-set()`, `image()`, `src()` and `~ +` combinators refused
  (`bridge/anim_packs.py`).
- XSS in the dev shell `app/device.html` (roster name unescaped). **Fixed**.
- `save-local-url` built a URL from the client's `Host`. **Fixed**: read from the socket address.
- MCP `diag_report` served to any paired device. **Fixed**: admin only.
- Dev probes (`routes_dev`: projreload, loadtest, fxprobe, chunkdump, namtest, fxdump, gapmeter, lcbench,
  rig_recall) drove REAPER from any paired phone. **Fixed**: admin only (`tools/check-*` run locally, local = admin).
- **Download integrity** — see §3 (fixed).
- Still true by design: the rack's LAN is plain HTTP and the bridge listens on `0.0.0.0` — the rack's network is a
  trusted network ([`network.md`](network.md)); `net.sh` passes the Wi-Fi key as a `sudo` argument
  (visible in local `ps`); the 6-digit pairing code (10 min, 10 attempts) can be burnt by a neighbour, not guessed.

Already sound: no `verify=False`; no secret in the repository (`.env` ignored, mode 600); pairing token written
0600; separation programs and keys admin-only with keys masked; `/ws` requires a token remotely; `.golem` files and
kit extraction protected (zip slip, links, caps); REAPER pinned by sha256; no shell command strings.

Tests: `tests/test_audit_2026_10_15_security.py`. Verified live: foreign Host → 403, import to 127.0.0.1 refused,
`http://golem.fm` refused, peaks without token from the LAN → 403, the app opens.

## 2. REAPER side (Lua / JSFX)

| Finding | Fix |
|---|---|
| **R1** the `rig_verify` pass (+2 s after a scene) *repaired* a file line by re-instantiating every FX of the lane, mid-song (gap + ~540 ms convolver stall) | it repairs only after a rebuild (`rig_verify_heal` set by `golem_watch`; the second pass of a rebuild keeps the right to repair); after a scene it only reports |
| **R2** a scene that falls back to a REBUILD did not arm the SETTLE; a stomp 30 ms later touched FX still loading | `golem_rig` sets `rig_rebuilt` on any rebuild; `golem_watch` arms the SETTLE |
| single command slot overwritten after 0.9 s while REAPER can hold its main thread longer: a command lost without trace | `bridge/commands.py` gained a bridge-side queue (see [`architecture.md`](architecture.md) §1.1); flushed on exit; `tests/test_command_queue.py` |
| `golem_looper.lua` replayed its last command (REC/PLAY) at startup or hot reload | `.looper-cmd.json` seq adopted at startup |
| looper track not armed (the unarmed-service-track trap) | armed `I_RECMODE 2`, `I_RECMON 1` |
| `golem_backing.lua` `jump`: load, unload, seek and transport stop did not clear an armed jump | `clear_jump` at those four places; a seek inside the section re-arms it (`tests/test_arrangement_practice.py`) |
| `plugin_window`: an instance recreated by chunk keeps its GUID, so a fresh instance could be read as an edit | per-track rewrite counter `GOLEM_CHUNK_GEN` in addition to the GUID |
| `.livemap.json`, `.knobmap.json` written without tmp + rename | written through `runtime.replace` |
| full Undo point on every stomp/scene (state serialized on the main thread) | no Undo block on stomp and scene |
| rebuild log emptied by every command; `golem_safety.jsfx` passed NaN from upstream; `golem_watch` without `pcall(tick)`; dev probe tracks at `I_RECMODE 0`; Windows absolute path not recognized in `golem_apply.lua` | log cleared only on recall/scene; NaN/inf replaced by silence; `golem_watch` survives a tick error; probes at `I_RECMODE 2`; path recognized |

Verified in REAPER: backing, looper and watch hot-reloaded without error, the looper replays nothing, `golem_rig` runs
a probe without truncating its log. **Not verified on the rig**: a full recall (rebuild → SETTLE, repair), a scene, a
practice jump followed by a song change, the NaN guard of `golem_safety` (EEL2 comparisons on NaN), the absence of
implicit Undo points. Positive trims after the limiter remain a mixing decision, not a fix.

## 3. Reproducibility and technical debt

**Fixed:**

- `bridge/requirements.txt` in exact versions; `requirements-dev.txt` (pytest, httpx, ruff, lupa);
  `bridge/requirements.lock` with hashes (`uv pip compile --universal --generate-hashes`), installed with
  `--require-hashes` by the Linux setup and by `provision/desktop.py` (simulated for Windows, macOS Apple Silicon and
  Intel, Linux; the simulation caught `onnxruntime` having no Intel-Mac wheel → pinned to an older version on macOS).
- The rack's venv lacked `httpx` (tests no longer collected) and `zeroconf` (listed, so `golem.local` did not
  resolve). Installed.
- `bridge/reaper_osc.py` opens its OSC port at startup, not at import (importing `bridge.app` while a bridge ran failed
  with "Address already in use"). A stale test of `reaper_update` was fixed.
- `ruff.toml` (narrow: syntax and undefined names). Its first run found **real errors**: `recall.py` read a variable
  local to another function — a NameError swallowed by a `suppress`, so the Whammy DT no longer received its PC on
  recall; `app.py` used an undefined `log` in four places and an unimported `_rig`.
- `tools/check-syntax.py`: syntax of every app JS module (node) and Lua script (luac or lupa, nothing executed).
- `.github/workflows/ci.yml`: on every push (Linux) — ruff, syntax, `node --test`, factory setup, pytest. Green on a
  clean clone with a fresh venv.
- **Local state out of the repository**: `config/click.json`, `compo.json`, `recorder.json` (defaults in code,
  `store.*_DEFAULTS`), `config/cards/` (registry of cards met), `config/inputmaps/` (rebuilt by `inputmap._seed`),
  `config/io.json` (active card deduced from the registry and the connected card), a personal setlist; generated Vital
  states, sample kinds and installed animation packs ignored. A new install now takes code defaults. Switching an
  older checkout to a newer one deletes or conflicts on these files, so `bridge/local_state.py` sets them aside and
  restores them (called by the built-in update; `tools/local-state.py pull` wraps a manual `git pull`;
  `tests/test_local_state.py`). A `.gitignore` line with a trailing comment matched nothing; fixed.
- `store._write_json_atomic` fsyncs before rename; the config writes that bypassed it now use it.
- **Download integrity**: `provision/lib-fetch.sh` `fetch_verified` + `provision/downloads.sha256`; an unpinned URL is
  refused (`GOLEM_ALLOW_UNPINNED=1` overrides), a wrong hash rejects the file. Used by `plugins.sh`, `plugins-deb.sh`,
  `install-plugins.sh`, `plugins-sws.sh`, `install-sfizz.sh`, `fetch-assets.sh`. Surge XT moved from a nightly to a
  pinned release; SWS pinned (and installed for the real user instead of root's home); sfizz pinned after its package
  repository key expired. Source builds stay pinned by commit; REAPER by `REAPER_SHA256`.
  `tests/test_downloads_pinned.py`.
- **REAPER update**: a validated version with no known hash is no longer installed unverified; a newer unvalidated
  version stays an admin choice, its hash logged.
- **Signed releases**: [`release-signing.md`](release-signing.md) — coded, inactive until a signing key is declared
  (`tests/test_release_sig.py`).
- **Licences and brand**: SPDX headers on every source file (GPL-3.0-or-later; MIT for the JSFX that are MIT); the
  vendored `tools/fcb/fcb1010.py` (third-party MIT code) got its header and `tools/fcb/LICENSE.fcb1010`; "GoleM" →
  "golem" in the README and bootstrap output.
- **Internal name of the cloud service** renamed to golem.fm: `bridge/golemfm.py`, routes `/api/golemfm/*`, key
  `"golemfm"` in `config/integrations.json`, `GOLEMFM_*` variables, `assets/*/golemfm/`. Dependency `source` is written
  `"golemfm"` (`preset_export.STORE_SOURCE`) and both old and new values are read (`STORE_SOURCES`). The rename
  briefly broke publishing personal kits and captures with a preset (a comparison on the new value while export still
  wrote the old one); fixed, `tests/test_store_source.py`.

**Remaining debt** (not refactored before publishing, on purpose: each line of the engine encodes a measured
trap): large modules (`routes_content.py`, `app.py`, `DesignerPage`, `golem_rig.lua`); `RigState` written from threads
and asyncio without a lock; many swallowed exceptions; duplicated helpers in Lua and Python↔JS tables; no executed
tests for Lua/JSFX (checked by `tools/check-*` on a live rig); the reference DI phrases are not published, so they
have no pinned hash yet.
