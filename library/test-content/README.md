# Test content

Content made **for the tests** (docs/quality-automation.md §8): patches, presets, setlists, a song and a standard,
all prefixed `test-`, generated by `tools/make-test-content.py` — edit the generator, not these files. Installed and removed
by `bridge/test_content.py` (`python -m bridge.test_content install|remove|status`), which keeps a ledger and never touches
the user's content. Every block type here is a REAPER built-in or a JSFX, so it materializes on any machine; the pads kit
and the drum kit are the factory ones, the grooves the factory grooves.
